# Keyboard Shortcuts

## Input Modes
| Key | Action |
|-----|--------|
| **Q** | Digit mode |
| **E** | Pencil marks mode |
| **R** | Color tag mode |
| **T** | Candidate color mode |

## Actions
| Key | Action |
|-----|--------|
| **P** | Auto-pencil (fill candidates) |
| **K** | Solve naked singles |
| **H** | Solve hidden singles |
| **B** | Toggle highlighting pairs |
| **N** | Generate new puzzle |
| **Ctrl+Z** | Undo |
| **/** | Show hint (press again to apply) |
| **F1** | Open help |

## Navigation
| Key | Action |
|-----|--------|
| **Arrow Keys** or **WASD** | Move selection (up/down/left/right) |
| **Right/D** | Move right |
| **Left/A** | Move left |
| **Down/S** | Move down |
| **Up/W** | Move up |

## Cell Input (on selected cell)
| Key | Action |
|-----|--------|
| **1-9** | Enter digit or toggle candidate |
| **Keypad 1-9** | Enter digit or toggle candidate (numpad) |
| **0** | Clear cell |
| **Backspace** | Clear cell |
| **Delete** | Clear cell |
